#Flutter UI Basics
##Overview
This project focuses on Git basics and Flutter UI fundamentals.
##Git Basics
The project was initialized with Git and includes multiple commits.
Basic Git commands practiced:
-git add
-git commit
-git push
-git pull
The Flutter project uses the default .gitignore configuration.
##Flutter Architecture
Flutter applications are built using widgets.
The project demonstrates:
-Widget Tree
-Build Method
-BuildContext
-StatelessWidget
-StatefulWidget
-Hot Reload

##Screens
The application contains four simple UI screens:
1-Profile Card
2-Simple Form
3-List of Items
4-Layout Widgets
A Navigation Bar is used to move between the screens.
##Stateless and Stateful Widgets
StatelessWidget :is used for screens and components whose content does not require changing state.
StatefulWidget :is used for the Simple Form and Navigation Bar where the UI changes based on user interaction.
##Result
The Flutter application was successfully built with multiple widgets, different UI layouts, StatelessWidget and StatefulWidget examples, and four simple screens with navigation.
