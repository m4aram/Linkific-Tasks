#Day 12 - Flutter SQLite

This project demonstrates local database management in Flutter using SQLite.

##Packages
1. sqflite
2. path
##Features
-SQLite database setup
1. DatabaseHelper
2. Create table
-CRUD operations
-Search
1. WHERE queries
2. ORDER BY
3. LIMIT and OFFSET
-JOIN queries
-Data models
-Data persistence
**CRUD**
Create — Insert new notes.
Read — Retrieve all notes or a single note.
Update — Edit existing notes.
Delete — Remove notes from the database.

##Database

The application uses SQLite for local data persistence.

##Testing

The application was tested by creating, reading, updating, deleting, searching, and persisting notes.
