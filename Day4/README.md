#Flutter Layouts
##Overview
This project focuses on Flutter layout widgets, responsive layouts, constraints, and complex UI design.
##Layouts
The application contains six complex layouts:
1-Instagram Post
2-WhatsApp Chat
3-E-commerce Products
4-Settings
5-Responsive Dashboard
6-Stack/Profile Layout
##Row and Column
The project uses Row and Column to arrange widgets horizontally and vertically.
It also demonstrates:
-mainAxisAlignment
-crossAxisAlignment
-mainAxisSize
-Nested Rows and Columns
##Flexible Layouts
The project demonstrates:
-Expanded
-Flexible
-Flex factors
Expanded is used to fill available space, while Flexible allows widgets to use available space more flexibly.
##Stack
The project uses Stack for overlapping UI elements.
It also demonstrates:
-Positioned
-Alignment
-Fit properties
##ListView
The project uses:
-ListView.builder
-ListView.separated
-Scrolling behavior
-Custom scroll physics
The ListView contains more than 100 items to demonstrate list performance.
##GridView
The project uses:
-GridView.count
-GridView.builder
-Grid delegates
-Responsive grid layout
##Responsive Design
The layouts are designed to adapt to different screen sizes and available space.
##Constraints
The project demonstrates how Flutter constraints affect widget size and layout behavior.
##Result
The application demonstrates multiple complex Flutter layouts, responsive design, ListView performance, GridView layouts, and Stack-based UI.
