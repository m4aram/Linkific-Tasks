Day 2 - Dart Fundamentals
##Overview
This training day focuses on learning Dart programming fundamentals and practicing the core concepts used in Flutter development.
##Learning Objectives
-Understand Dart language basics
-Learn Dart syntax
-Understand Object-Oriented Programming (OOP)
-Practice asynchronous programming
-Understand null safety
-Practice Dart collections
