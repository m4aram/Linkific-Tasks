#Material Design App
##Overview
This project demonstrates Flutter Material Design and Material 3 components.
##Main Screens
-Login Screen
-Register Screen
-Dashboard Screen
-Material Form Screen
##Material Design Widgets
The application uses more than 10 Material widgets, including:
* MaterialApp
* Scaffold
* AppBar
* ElevatedButton
* TextButton
* OutlinedButton
* FilledButton
* IconButton
* FloatingActionButton
* Card
* ListTile
* CircleAvatar
* AlertDialog
* SimpleDialog
* BottomSheet
* SnackBar
* MaterialBanner
* TextField
* TextFormField
* Form
* DropdownButtonFormField
* SwitchListTile
* Modal Bottom Sheet

##Buttons
The application demonstrates different Material buttons:

##Cards and Lists
The Dashboard screen uses Card and ListTile widgets to display users, orders, and revenue information.

The Register and Material Form screens use Form and TextFormField widgets with validation rules.

The application demonstrates:

##Navigation
The application uses named routes to navigate between screens.
